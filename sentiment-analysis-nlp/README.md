# Review Sentiment Analyzer

A small end-to-end NLP project that classifies customer reviews as **Positive**, **Neutral** or **Negative**, and serves predictions through a Streamlit app.

I treated it as a supervised, multi-class text classification problem: clean the text, turn it into TF-IDF features, train a few classical models, compare them fairly, and ship the best one.

## How it works

```
review text -> cleaning -> TF-IDF (1-2 grams) -> classifier -> label + confidence -> Streamlit UI
```

1. **Cleaning** (`src/preprocess.py`): lowercase, remove URLs / @mentions / HTML, expand contractions, tokenize, remove stop words, lemmatize with NLTK. Negation words (`not`, `never`, `no`...) are deliberately kept, because "not good" and "good" mean opposite things.
2. **Features**: `TfidfVectorizer` with unigrams and bigrams, `min_df=2`, `max_df=0.9`, up to 20,000 features.
3. **Models compared**: Multinomial Naive Bayes, Logistic Regression, Linear SVM (probability-calibrated so it can output a confidence).
4. **Model selection**: 5-fold stratified cross-validation on the *training* set using macro F1, then a small grid search on the winner. The test set is only used once, at the end.
5. **Serving**: the whole thing (cleaner + TF-IDF + model) is one scikit-learn `Pipeline` saved with joblib, so the app never has to retrain or re-fit anything.

### Avoiding data leakage
The train/test split happens before anything is fitted. TF-IDF sits inside the `Pipeline`, so it is fitted on training folds only and merely *applied* to validation and test text.

## Results on the bundled sample data

| Model | CV macro-F1 | Test accuracy | Test macro-F1 |
|---|---|---|---|
| Naive Bayes | 0.918 | 0.901 | 0.895 |
| Logistic Regression | 0.915 | 0.905 | 0.898 |
| Linear SVM | 0.913 | 0.905 | 0.898 |

Selected model: **Naive Bayes** (highest CV score; the three are within noise of each other). Inference is about 0.5 ms per review. Full report in `models/classification_report.txt`, confusion matrix in `assets/confusion_matrix.png`.

> **Important:** `data/sample_reviews.csv` is a small *synthetic* dataset generated by `scripts/make_sample_data.py` so the repo runs immediately. These numbers show the pipeline works, not how it performs on real customer reviews. Retrain on a real dataset (below) and replace this table with your own results.

## Run it

```bash
git clone https://github.com/<your-username>/sentiment-analysis-nlp.git
cd sentiment-analysis-nlp
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python -m src.train              # trains, compares models, saves models/ and assets/
streamlit run app.py             # opens the web app
python -m src.predict "The camera quality is fantastic."   # quick CLI test
```

## Using a real dataset

Any CSV with a text column and a sentiment column works. Labels can be `negative/neutral/positive`, `neg/neu/pos` or `0/1/2`.

```bash
python -m src.train --data data/raw/Tweets.csv --text-col text --label-col airline_sentiment
```

Good 3-class options: the Kaggle *Twitter US Airline Sentiment* dataset, or Amazon product reviews with star ratings mapped to labels (1-2 = Negative, 3 = Neutral, 4-5 = Positive). Put big files in `data/raw/`, which is git-ignored.

## Project structure

```
app.py                      Streamlit app (predict + model info tabs)
src/config.py               paths, labels, seed, split size
src/data.py                 CSV loading, label cleaning, dedup
src/preprocess.py           TextCleaner (sklearn transformer)
src/train.py                split, compare, tune, evaluate, save
src/predict.py              load model, predict one review
scripts/make_sample_data.py builds the synthetic demo dataset
models/                     saved pipeline, metrics.json, comparison, report
assets/confusion_matrix.png
```

## Limitations

- TF-IDF only sees word statistics, not context. Sarcasm, slang ("this is sick") and mixed reviews ("great screen, awful battery") are hard for it.
- A single label per review can't say *which* feature was liked or disliked.
- English only; the bundled data is synthetic.

## Future improvements

- Swap TF-IDF + linear model for DistilBERT / BERT and compare.
- Aspect-based sentiment (battery -> negative, camera -> positive).
- Hindi / Hinglish support.
- Wrap the model in a FastAPI service and monitor prediction drift.
